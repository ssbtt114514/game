# 验收清单（§10）

## 核心玩法

- [x] 五个阶段随分数推进：0 / 100 / 800 / 10000 / 50000。
- [x] 阶段一 6×1×12 一维线段；阶段二 10×1×20 二维四格骨牌；阶段三起 10×10×20 三维场地。
- [x] 三维方块绕 x / y / z 三轴旋转，带踢墙；预览与相机自动取景。
- [x] 列消除 +20、行消除 +50、排/列 +100、层 +500。
- [x] 阶段四起按颜色消除（≤4 色整体 +500）并支持 2–4 阶魔方检测（每层 +500）。
- [x] 阶段五流体：水/岩浆下落与侧向扩散，岩浆半速，水+岩浆凝结。
- [x] 六种道具与四种随机事件的触发、瞄准、效果与 HUD 倒计时。
- [x] 阶段五方块属性：重力、气体、液体、染色，可叠加。
- [x] 红线判负、锁定判负、暂停与重开。

## 数值与规则

- [x] §2 锁定数值未被修改：阶段阈值、四类计分、场地尺寸、五档速度与掉率、不可暂停难度。
- [x] 扁平一维数组 `idx = x + y*w + z*w*d`。
- [x] 极限场地 100×100×50 = 50 万格可创建与游玩。
- [x] 流体只处理活跃集合，约 100ms 一次 tick，无全场景扫描。

## 界面与交付

- [x] 启动菜单：难度、种子、自定义场地（尺寸/维度/速度）、静音、设置导入导出。
- [x] 暂停菜单：继续、重开、读档、静音、返回主菜单；难/极难不可暂停。
- [x] 自动存档与读档：场地、分数、阶段、库存、事件、RNG、队列。
- [x] WebAudio 合成音效，无第三方版权素材。
- [x] 移动端触屏操作区与窄屏布局。
- [x] 单元/集成/性能测试全绿，类型检查与生产构建通过。
- [x] GitHub Actions CI 自动执行测试与构建。

## 已知限制

- 无 GPU 环境下渲染帧率受 SwiftShader 限制，逻辑层不受影响。
- 生产包未做代码分割，Three.js 使单 chunk 超过 500 kB（gzip 约 146 kB）。
- 墙壁炸弹简化处理：洞口方块落底，不模拟横向坠出边界（ASSUMPTIONS #24）。
